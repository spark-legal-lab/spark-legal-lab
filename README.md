# 星火法律实验室

**一起把想法做成工具，把实践沉淀为可复用的方法。**

这里是由「星火计划」学员自发发起的法律 AI 共创空间，欢迎同学参与，也欢迎对法律科技感兴趣的朋友交流。

> 本仓库为学员自主共创项目，非主办方或培训班官方仓库。

## 现在有什么？

仓库刚刚起步，目前尚无可共享项目。我们先把交流与协作的入口建起来，逐步积累：

- **实用工具**：从法律工作中的具体需求出发，共同开发小工具。
- **Skills 与工作流**：分享自己编写、实际使用过的技能与操作方法。
- **实践笔记**：记录尝试过程、适用条件、局限与踩坑经验。
- **项目共创**：提出需求、寻找伙伴，把有价值的想法一起做出来。

## 怎么参与？

不需要先会编程，也不需要先完成一个项目。

1. **有需求或想法**：到 [Issues](https://github.com/csslaw/spark-legal-lab/issues/new/choose) 选择「共创提案」，说说遇到的问题。
2. **愿意参与**：在感兴趣的提案下留言，说明你能提供的帮助，例如业务经验、需求梳理、测试、文档或开发。
3. **已有成果**：按 [参与指南](CONTRIBUTING.md) 提交 Pull Request（修改提案），由维护者审核后合并。
4. **想持续共建**：通过「申请共建」Issue 说明参与意向与方向，维护者审核后按协作需要发出邀请。

提交 Issue、参与讨论，无需先获得仓库写入权限。收藏关注可以点 Star。

## 分享前请确认

- 分享自己有权公开的内容，并注明作者、来源与适用范围。
- 讲师课件、他人笔记、培训资料，仅在取得相应授权后上传；也可以分享公开来源链接。
- 请勿上传真实案件材料、当事人信息、班级通讯录、账号口令或 API 密钥；示例优先使用虚构数据。
- 对 AI 生成或辅助完成的内容，请说明验证方式与已知局限。涉及法律结论时，请注明依据及核验日期。

## 关于许可

当前仓库尚未设置统一开源许可证，公开可见不表示可以任意转载、修改或商用。具体成果的使用条件由贡献者与维护者确认后，在对应目录说明。

欢迎提出第一个问题，也欢迎认领第一个想法。
